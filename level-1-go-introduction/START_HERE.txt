🚀 QUICK START (5 MINUTES):

# 1. Verify Go installation
go version

# 2. Create project
mkdir ~/my-go-app && cd ~/my-go-app

# 3. Initialize module
go mod init example.com/hello

# 4. Create program
cat > main.go << 'PROG'
package main
import "fmt"
func main() {
    fmt.Println("Hello, Go!")
}
PROG

# 5. Run it
go run main.go

# 6. Build it
go build

# 7. Run executable
./main

💡 KEY CONCEPTS:

Package main      - Executable program entry point
func main()       - Where program starts executing
import "fmt"      - Include formatting package
go run            - Compile & run directly
go build          - Create standalone executable
go mod init       - Initialize project module
go fmt            - Format code to Go standard
