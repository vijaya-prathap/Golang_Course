================================================================================
                      THE BIG PICTURE
================================================================================

What is a Type?
  → A category of data (int, string, float, bool)
  → Tells Go how much memory to use
  → Tells Go what operations are allowed

Example types:
  int          → Whole numbers (-5, 0, 42)
  float64      → Decimals (3.14, 2.71)
  string       → Text ("Hello", "World")
  bool         → True or false

Why Types Matter:
  → Safety: Can't accidentally use string as number
  → Performance: Go knows exactly how much memory needed
  → Clarity: Code is more readable

================================================================================
                 THE THREE WAYS TO DECLARE VARIABLES
================================================================================

This is the MOST IMPORTANT concept in Level 3!

Method 1: var with type (explicit)
  var name string = "Alice"
  var age int = 25
  
  Use when: Package level, type not obvious

Method 2: var with inference (type inferred from value)
  var name = "Alice"     // Go figures out it's string
  var age = 25           // Go figures out it's int
  
  Use when: Package level, type is obvious

Method 3: Short declaration := (inside functions only!)
  name := "Alice"        // Same as var name = "Alice"
  age := 25              // Same as var age = 25
  
  Use when: Inside functions, quick and clean

KEY RULE: := ONLY WORKS INSIDE FUNCTIONS!

```
func main() {
    x := 5  ✅ OK - inside function
}

x := 5      ❌ ERROR - package level!
```

================================================================================
                        BASIC DATA TYPES
================================================================================

Go has these basic types:

Integers (whole numbers):
  int     → Default integer type (32 or 64 bit)
  int8    → -128 to 127
  int32   → Larger range
  int64   → Even larger range
  uint    → Unsigned (0 or positive only)
  
Example:
  var count int = 42
  age := 25

Floats (decimals):
  float32 → 32-bit (less precise)
  float64 → 64-bit (more precise) - DEFAULT
  
Example:
  var pi float64 = 3.14159
  tax := 0.08

Strings (text):
  string  → "Hello, World!"
  
Example:
  var greeting string = "Hello"
  name := "Alice"

Booleans (true/false):
  bool    → true or false
  
Example:
  isActive := true
  isValid := false

Special Types:
  byte    → For single byte values (0-255)
  rune    → For Unicode characters

================================================================================
                      THE ZERO VALUE CONCEPT
================================================================================

This is UNIQUE to Go!

When you declare a variable WITHOUT initializing it, Go gives it a ZERO value:

var i int       → 0
var f float64   → 0.0
var s string    → "" (empty string)
var b bool      → false

Why this matters:
- Variables are NEVER uninitialized
- NEVER undefined or null (except pointers)
- Variables are ALWAYS ready to use
- Predictable default behavior

Example:
  var count int      // count is 0, not undefined!
  count += 5         // Now count is 5
  fmt.Println(count) // Prints: 5

================================================================================
                      TYPE CONVERSION
================================================================================

KEY RULE: Go does NOT allow automatic type conversion!

You MUST convert explicitly.

Wrong:
  var i int = 42
  var f float64 = i  // ❌ ERROR!

Right:
  var i int = 42
  var f float64 = float64(i)  // ✅ OK

Common Conversions:

  int to float64:         float64(42)
  float64 to int:         int(3.14)      // Loses decimal!
  int to string:          strconv.Itoa(42)
  string to int:          strconv.Atoi("42")

Example:
  package main
  import "strconv"
  
  str := "123"
  num, err := strconv.Atoi(str)  // "123" → 123
  result := strconv.Itoa(456)    // 456 → "456"

================================================================================
                          CONSTANTS
================================================================================

Constants are like variables but CANNOT be changed:

var x = 10
x = 20  ✅ OK - variables can change

const y = 10
y = 20  ❌ ERROR! - constants cannot change!

Use constants for:
- Values that should NEVER change
- Making intent clear (this is fixed)
- Preventing accidental modification

Example:
  const AppName = "MyApp"
  const MaxConnections = 100
  const Pi = 3.14159

You can also use iota for sequences:
  const (
      Monday = iota      // 0
      Tuesday            // 1
      Wednesday          // 2
  )

================================================================================
                        NAMED TYPES
================================================================================

You can create custom names for existing types:

type Age int
type Temperature float64
type UserId string

Example:
  type Age int
  
  myAge := Age(25)
  yourAge := Age(30)

Why named types?
  1. TYPE SAFETY - Can't accidentally mix different types
  2. DOCUMENTATION - Code explains what value represents
  3. METHODS - Can add methods to named types

Example with methods:
  type Age int
  
  func (a Age) IsAdult() bool {
      return a >= 18
  }
  
  myAge := Age(25)
  if myAge.IsAdult() {
      fmt.Println("Adult")
  }

================================================================================
                    A SIMPLE EXAMPLE
================================================================================

Let's declare variables:

package main

import "fmt"

func main() {
    // Method 1: var with type
    var firstName string = "Alice"
    var age int = 25
    
    // Method 2: var with inference
    var city = "New York"
    
    // Method 3: short declaration
    email := "alice@example.com"
    
    // Constants
    const appVersion = "1.0"
    
    // Display
    fmt.Println("Name:", firstName)
    fmt.Println("Age:", age)
    fmt.Println("City:", city)
    fmt.Println("Email:", email)
    fmt.Println("Version:", appVersion)
}

Output:
  Name: Alice
  Age: 25
  City: New York
  Email: alice@example.com
  Version: 1.0

================================================================================
                    COMMON MISTAKES TO AVOID
================================================================================

❌ WRONG: Automatic type conversion
  var i int = 42
  var f float64 = i

✅ RIGHT: Explicit conversion
  var f float64 = float64(i)

---

❌ WRONG: Using := at package level
  package main
  count := 42

✅ RIGHT: Use var at package level
  package main
  var count = 42

---

❌ WRONG: Re-declaring with :=
  name := "Alice"
  name := "Bob"  ← Error!

✅ RIGHT: Reassign instead
  name := "Alice"
  name = "Bob"   ✅ OK

---

❌ WRONG: String indexing gives character
  s := "Hello"
  c := s[0]  ← Returns 72, not 'H'!

✅ RIGHT: Convert to string
  c := string(s[0])  ← Returns "H"

================================================================================
                      QUICK FAQ
================================================================================

Q: What's the difference between var and :=?
A: var works anywhere, := only in functions. := is faster to type.

Q: Do I need to memorize all the types?
A: No. Start with int, float64, string, bool. Learn others as needed.

Q: Why is type conversion required?
A: To prevent accidental bugs. You must think about what you're doing.

Q: What if I forget := vs var?
A: If inside function: use :=
   If package level: use var

Q: Can I mix int and float in calculations?
A: No! Must convert: float64(intValue) or int(floatValue)
